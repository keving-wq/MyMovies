Movie Review Portal

A simple C# and ASP.NET Core MVC web app where staff can manage movie listings and critics can write reviews.

What Is This Project?

This app is the **Admin Website** inside a larger 4-part system.
**Admin Website (This App):** Staff and critics add, edit, or delete movies.
**Database:** Stores all movie data in SQL Server.
**API:** Sends movie data to other apps using JSON format.
**Public Website:** A React website where visitors browse movies and reviews.

Features
* View a list of movies (Title, Genre, Release Date, Director).
* Add new movies to the catalog.
* Built using C#, Razor Views, and Bootstrap styling.
